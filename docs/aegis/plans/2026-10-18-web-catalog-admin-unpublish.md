# Web 模组目录详情：管理员下架项目计划

日期：2026-10-18。状态：已实施完成，本地自动化测试通过。

## 目标与范围

管理员能在 Web「模组目录 → 项目详情」直接下架整个项目，而非仅下架当前版本。

- 项目从公开目录隐藏，版本、归档和详情图保留，不执行删除。
- 新入口仅管理员可见，作者工作台既有能力保持不变。
- 复用现有接口，不新增数据库字段或迁移脚本。
- 不扩展批量下架、重新上架、强制理由或项目级审计流程。

## 风险与完成标准

- 前端隐藏按钮不是权限边界，以服务端校验为准。
- 下架不撤销已下载文件，公开资源访问语义沿用现有后端行为。
- 项目可以保留在作者或管理员工作区集合中，公开目录必须依据公开状态过滤。
- 不顺带修改 GitHub 同步、自动发布或重新上架规则；若实施时发现会覆盖下架状态，单独记录并确认范围。
- 不修改无关工作区变更，不自行提交 Git commit。

完成标准：管理员在目录详情中可完成项目级下架，成功与失败交互正确、数据保留、自动验证通过，并记录测试服务器验收证据。未完成服务器验收前，不宣称线上行为已验证。
